# P2.5 — `error`, `warning`, `info`, and `MAKECMDGOALS` (one session)

After P2.4b. Three message functions and one special variable. gmake's words, pasted from 4.4.1: `$(info text)` prints
`text` on stdout when it is expanded and expands to nothing; `$(warning text)` prints `FILE:LINE: text` on stderr and
expands to nothing; `$(error text)` is fatal: `FILE:LINE: *** text.  Stop.` and exit 2, where LINE is the line of the
reference. **gmake expands every line of a recipe before it runs the first one**, so an `$(error)` on recipe line 3
fires before line 1's command runs, and nothing of that recipe is printed. A top-level line that is only a function call
(`$(info reading)`) is expanded when read; one that expands to nothing is nothing (no "missing separator").
`MAKECMDGOALS` is the goals from the command line, space-joined (empty when none). **Stop only at `wolf test` green
(68 passed) and `Results: 227 passed, 0 failed`** (219 today + five rows + three bad rows).

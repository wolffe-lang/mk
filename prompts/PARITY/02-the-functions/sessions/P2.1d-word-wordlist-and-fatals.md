# P2.1d — the no-`%` pattern fix, gmake's fatal line shape, `word` and `wordlist` (one session)

Two things first, then the two functions. Every expected byte comes from `gmake` 4.4.1 (the reviewer's witnesses):
- `$(patsubst a,x,a aa b)` → `x aa b` — a pattern without `%` matches a whole word; today `apply_pattern_sub` (expand.lu)
  reads `pattern.find("%") else 0` and treats a missing `%` as one at position 0, so mk prints `x x x` and
  `test_function_patsubst_first_percent` traps.
- `$(word x, foo bar)` → stderr `Makefile:2: *** invalid first argument to 'word' function: 'x'.  Stop.`, exit 2;
  `$(word 0, foo bar)` → `*** first argument to 'word' function must be greater than 0.  Stop.`;
  `$(word , foo bar)` → `*** invalid first argument to 'word' function: empty value.  Stop.`;
  `$(wordlist x, 2, foo bar)` → `*** invalid first argument to 'wordlist' function: 'x'.  Stop.`;
  `$(wordlist 0, 2, foo bar)` → `*** invalid first argument to 'wordlist' function: '0'.  Stop.` (0 is "invalid" for wordlist,
  "must be greater than 0" for word);
  `$(wordlist 1, y, foo bar)` → `*** invalid second argument to 'wordlist' function: ' y'.  Stop.` (the second argument's text
  is quoted as written, its leading space included);
  `$(word 2, foo bar baz)` → `bar`; `$(word 5, foo bar baz)` → empty; `$(wordlist 2, 3, foo bar baz)` → `bar baz`;
  `$(wordlist 3, 2, foo bar baz)` → empty.
  The fatal line's shape is `FILE:LINE: *** MESSAGE.  Stop.` with NO `mk:` prefix (gmake's); mk's refusals today print
  `mk: FILE:LINE: MESSAGE`. The rule this session adds: a `Refuse` whose message starts with `*** ` is a gmake fatal and prints
  as `FILE:LINE: MESSAGE.  Stop.`; every other refusal prints as before.

```
/// A refusal whose message starts with "*** " is a gmake fatal line:
/// `FILE:LINE: *** MESSAGE.  Stop.` with no `mk:` prefix. Every other
/// refusal keeps mk's own shape, `PREFIXFILE:LINE: MESSAGE`.
fn refusal_text(prefix: str, file: str, line: int, msg: str) -> str {
    if msg.starts_with("*** ") {
        return "{file}:{line}: {msg}.  Stop."
    }
    "{prefix}{file}:{line}: {msg}"
}

/// A word index argument: the digits of `text` (whitespace trimmed) as a
/// number, or gmake's fatal message naming the argument as written.
fn word_index(text: str, fname: str, which: str, line: int) -> int ! {Refuse(int, str)} {
    let t = text.trim()
    if t.len == 0 {
        return Refuse(line, "*** invalid {which} argument to '{fname}' function: empty value")
    }
    var i = 0
    while i < t.len {
        let c = t[i..i + 1]
        if c < "0" || c > "9" {
            return Refuse(line, "*** invalid {which} argument to '{fname}' function: '{text}'")
        }
        i = i + 1
    }
    let n = t.to_int() else 0
    if n == 0 && fname == "word" {
        return Refuse(line, "*** first argument to 'word' function must be greater than 0")
    }
    if n == 0 {
        return Refuse(line, "*** invalid {which} argument to '{fname}' function: '{text}'")
    }
    n
}
```

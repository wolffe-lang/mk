# P2.6 — `$(shell …)` and the `!=` assignment (one session)

After P2.5. gmake's words, measured on 4.4.1: `$(shell cmd)` runs `cmd` with `/bin/sh -c` and expands to its standard
output, the trailing newlines dropped and every other newline turned into a space; the command's standard error goes to
the terminal. A `=` variable's `$(shell …)` runs each time the variable is expanded; a `:=` one once, when read.
`V != cmd` expands `cmd`, runs it once when read and stores the output as a **recursive** variable (`$(flavor V)` is
`recursive`); a failing command still assigns its output. `N!=echo n` (no spaces) is the same assignment, not a variable
named `N!`. Today mk refuses `$(shell` and reads `A != …` as a missing separator. `.SHELLSTATUS` is P2.6b, not this

/// Run `cmd` with `/bin/sh -c`, as gmake's $(shell …) and `!=` do: the
/// child's standard output with the trailing newlines dropped and every
/// other newline turned into a space, and its exit status. The child's
/// standard error is this program's.
fn shell_output(cmd: str) -> (str, int) {
    let p = process.pipe() else |e| match e {
        io => return ("", 127),
    }
    let c = process.command("/bin/sh")
    process.push_arg(mut c, "-c")
    process.push_arg(mut c, cmd)
    process.set_stdout(mut c, p.write)
    let child = process.start(c) else |e| match e {
        unsupported => return ("", 127),
        invalid => return ("", 127),
        not_found => return ("", 127),
        denied => return ("", 126),
        io => return ("", 127),
    }
    fs.close(take p.write) else |e| match e {
        io => {},
    }
    var out = ""
    var reading = true
    while reading {
        let chunk = fs.read(mut p.read, 4096) else |e| match e {
            eof => "",
            io => "",
            utf8 => "",
        }
        if chunk.len == 0 {
            reading = false
        } else {
            out = out + chunk
        }
    }
    fs.close(take p.read) else |e| match e {
        io => {},
    }
    let status = process.wait(take child) else |e| match e {
        signal => 128,
        io => 127,
    }
    var end = out.len
    while end > 0 && out[end - 1..end] == "\n" {
        end -= 1
    }
    (replace_all(out[0..end], "\n", " "), status)
}

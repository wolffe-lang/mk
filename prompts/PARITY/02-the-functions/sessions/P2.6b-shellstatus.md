# P2.6b — `.SHELLSTATUS` (one session)

GNU make 4.4.1, measured below: before a shell, `.SHELLSTATUS` is empty and its origin and flavor are `undefined`. `$(shell exit 3)` sets `3`; `true` sets `0`; `Z != false` sets `1`. Once set, origin is `override`, flavor is `simple`. `R = $(shell exit 7)` runs nothing until expanded; `$(info use [$(R)] [$(.SHELLSTATUS)])` prints `use [] [7]`, and the next top-level call still sees `7`. Signal 9 gives `137`. Output and status are independent: `echo hi; exit 2` gives `hi` and `2`. A recipe sees the new status later in the same line.

Use a mutable `ShellStatus` cell, threaded alongside `visiting`, and keep `expand`'s public signature. `expand_status` returns the output and last status (`-1` means no shell); `expand_store` persists it for mutable callers. Thread the cell through `expand_var` and `try_substitution` too, so recursive variables and substitution references do not lose it. `origin`, `flavor`, and `value` must see the cell before the table is updated. `process.wait` loses the signal number; use `process.wait_status` (exit code or negative signal), then `128 - ended` for a negative result. The signal row and unit test measure `137`.

The other three recipe expansion sites have read-only `v`; leave them on `expand`, whose cell supplies within-line visibility. This session does not make the recipe callers mutable or claim status persistence between separate recipe expansions, conditionals, or graph expansions.

fn expand(v: Vars, s: str, line: int) -> str ! {
    Unterminated(int, str),
    Cycle(int, str),
    Refuse(int, str),
} {
    let (out, _status) = expand_status(v, s, line)?
    out
}

/// Keep expand's read-only interface; mutable callers can persist the status.
fn expand_status(v: Vars, s: str, line: int) -> (str, int) ! {
    Unterminated(int, str),
    Cycle(int, str),
    Refuse(int, str),
} {
    var st = ShellStatus { last: -1 }
    let out = expand_inner(v, s, "", line)?
    (out, st.last)
}

fn expand_store(mut v: Vars, s: str, line: int) -> str ! {
    Unterminated(int, str),
    Cycle(int, str),
    Refuse(int, str),
} {
    let (out, status) = expand_status(v, s, line)?
    store_shell_status(mut v, status, line)
    out
}

fn test_shellstatus_cell() {
    let v = new_vars()
    let (empty, absent) = expand_status(v, "$(.SHELLSTATUS)", 1) else ("error", -2)
    assert(empty == "" && absent == -1, "no shell leaves the sentinel")

# P3.2 — recipe lines (one session)

Measured at `aa5fd08` on wolf 0.2.36 against GNU make 4.4.1, each probe in a fresh directory; every edit below was built and run green on a clone first.

**A recipe line inside a conditional.** gmake keeps the recipe lines of `all:` / `ifeq (a,a)` / `\t@echo yes` / `endif` / `\t@echo after` for `all` (`yes`, `after`). mk ended the rule at the `ifeq` line and dropped every recipe line after it: `mk: Nothing to be done for 'all'.`. Now only a live line other than a conditional directive ends a rule (a line in a branch not taken does not). A recipe line in a branch not taken is dropped.

**A tab line outside a rule.** gmake reads one that is a directive or an assignment as a makefile line (`\tX = 1` before the first target sets `X`). It skips one that is blank or a comment. Any other stops it: `commence.mk:2: *** recipe commences before first target.  Stop.`, and the same after an assignment that ends a rule, or in an included file. mk ignored them all. After `.PHONY:`, `.EXPORT_ALL_VARIABLES:` or a refused rule, a tab line is that rule's recipe and stays ignored (`special_rule`). The new `tab_line_is_makefile_line` in parse.lu decides.

**A tab continuation.** `all: a \` then `\tb` is one rule line (prerequisites `a b`), and `X = a \` then `\tb` is `a b`. `join_continuations` took the tab line for a recipe line.

**The prefix characters.** gmake skips spaces and tabs before, between and after `@`, `-` and `+`: `\t  @echo x` is silent, `\t@ - exit 2` is ignored (`mk: [space.mk:4: all] Error 2 (ignored)`), and `\t   echo shown` echoes `echo shown`. mk passed `@echo` to the shell (`strip_prefixes` in run.lu).

**The warning's line.** gmake's overriding-recipe warnings name each recipe's first line (`warn.mk:4:` and `warn.mk:2:` for rules on lines 1 and 3). mk named the rules' lines (`add_node` in graph.lu).

`same_as_make` normalises line numbers, so `warn` passes `test.sh` even while red; step 34's byte-for-byte compare checks it.

/// an assignment. Any other there is `recipe commences before first target`.
fn tab_line_is_makefile_line(line: str) -> bool {
    let w = line.trim()
    if parse_conditional(w).len > 0 {
        return true
    }
    let words = w.words()
    let first = if words.len > 0 then words[0] else ""
    if first == "define" || first == "endef" || first == "include" || first == "-include" {
        return true
    }
    if first == "sinclude" || first == "export" || first == "unexport" || first == "override" {
        return true
    }
    if first == "undefine" {
        return true
    }
    let _a = parse_assignment(w, 0) else {
        return false
    }
    true
}
